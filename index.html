Documentation

What is elysnipe?

A tool for the Elysium network that shows info about a token or wallet and lets you snipe the token launches of a chosen dev.

Token CA mode

Paste a contract address (0x + 40 hex characters). You will see the token name, symbol, supply, holders and liquidity.

Dev wallet mode

Paste a dev wallet address. You will see its balance, number of created tokens and activity. After you press Snipe it, the wallet is monitored and every new token from that dev is bought instantly.

How does sniping work?
  1. Monitor deployments from the chosen address.
  2. Detect the new token and pool addresses.
  3. Buy in the first available block.
Risks

Sniping is high risk: tokens can turn out to be scams. Never invest more than you can afford to lose. This is not financial advice.
